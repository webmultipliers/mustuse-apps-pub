# Hero Block

**Pattern demonstrated:** Static structural composition with optional CTA navigation.

The hero block is a top-of-screen visual anchor combining a background image, heading, subheading, and optional call-to-action button. It shows how to:

- Use `container` with a background image
- Compose a `stack` of text and interactive elements
- Use `visible_when` for conditional rendering (CTA only shows when configured)
- Wire a `button` action to a navigation target with typed destination (URL, screen, deeplink)

This is the simplest structural composition pattern. Start here if your block arranges static content with optional interactivity.
