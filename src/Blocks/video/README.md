# Video Block

**Pattern demonstrated:** Media player with attribute-driven configuration.

The video block renders an inline video player with a poster image and optional caption. It shows how to:

- Use `video_player` with `src` and `poster` attributes
- Access nested media attribute fields (`{{ attributes.posterImage.url }}`)
- Compose media + caption in a vertical stack

This is the video variant of the media display pattern. See the `image` block for the static image equivalent.
