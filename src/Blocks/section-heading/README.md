# Section Heading Block

**Pattern demonstrated:** Minimal text with heading style and visual divider.

The section-heading block renders a heading with a hairline rule below it. It shows how to:

- Use `text` with a dynamic `style` driven by an attribute (`{{ attributes.level }}`)
- Use `divider` for visual separation
- Keep renderer descriptions minimal — two elements, no data fetching, no interactivity

This is the simplest structural pattern. Use it as a template for blocks that are pure layout with no data binding.
